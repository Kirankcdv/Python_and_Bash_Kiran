# Python & Bash - DevOps Assignment

## Overview

This project demonstrates basic Python programming concepts required for the DevOps assignment.

The project covers:

- Conditional statements
- Dictionaries
- User input
- File handling
- Reading and writing text files

## Tasks

### 1. Grade Checker

File: `01_grade_checker.py`

This program takes a score as input and determines the corresponding grade using `if`, `elif`, and `else` statements.

Grade ranges:

- 90 and above: A
- 80–89: B
- 70–79: C
- 60–69: D
- Below 60: F

### 2. Student Grades

File: `02_student_grades.py`

This program uses a Python dictionary to store student names and grades.

The user can:

- Add a new student
- Update an existing student's grade
- Display all student grades

### 3. Write to a File

File: `03_write_to_file.py`

This program creates `sample.txt` and writes content into it using Python's `open()` and `write()` functions.

### 4. Read from a File

File: `04_read_from_file.py`

This program opens `sample.txt` in read mode and uses `file.read()` to display its contents.

## How to Run

Make sure Python is installed.

Run the programs using:

```bash
python3 01_grade_checker.py
python3 02_student_grades.py
python3 03_write_to_file.py
python3 04_read_from_file.py
